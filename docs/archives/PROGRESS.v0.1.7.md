**Scope**: 4-stage rolling-wave delivery — Phase 0 fact validation → Phase 1 spec/design → Phase 2 self-contained hooks (PreCompact handoff + SessionStart resume + macOS notify) → Phase 3 full launchd-based daemon (cross-session spawn + gate.lock sentinel + git stash safety net + push notifier).
